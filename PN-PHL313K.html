The complete operator set for propositional logic

What Is Sentential Logic?

Sentential logic (also called propositional logic) studies how statements — sentences that are either TRUE or FALSE — combine using logical operators to form compound statements. Variables like P, Q, and R stand in for any such statement.

Predicate Logic & Set Theory

Quantifiers, domains, set operators, and the ±∞ spectrum

What Is Predicate Logic?

Sentential logic treats whole sentences as atomic units. Predicate logic opens them up — it lets us talk about objects, properties, and relations. Three building blocks: Terms (objects), Predicates (properties applied to terms, e.g. P(x)), Quantifiers (how many objects the predicate applies to).

Predicate Notation

SymbolNameRead As
P(x)Predicate"x has property P"
∀xUniversal Quantifier"For all x… / Every x…"
∃xExistential Quantifier"There exists an x… / Some x…"
¬∃xNegated Existential"There is no x… / No x…"
∃!xUnique Existential"There exists exactly one x…"
∀x ∀yNested Universal"For all x and for all y…"
∃x ∃yNested Existential"There exists an x and a y…"
DDomain of DiscourseThe universe of objects x ranges over

The Domain of Discourse

The domain D determines what "all" and "some" refer to. Changing D can flip a statement's truth value:

D = {humans}
∀x P(x) where P(x) = "x is mortal"
→ TRUE — every human is mortal.
D = {gods, humans}
∀x P(x) where P(x) = "x is mortal"
→ FALSE — gods are not mortal.
Rule: Always specify your domain. An unspecified domain is an unfinished statement.

Universal Quantifier — ∀x P(x)

Meaning: P holds for every object in the domain. FALSE if even one object fails.

Example: D = {Alice, Bob, Carol}, P(x) = "x has studied logic" → All three must hold.
The edict of an absolute sovereign — one exemption breaks the decree.

Existential Quantifier — ∃x P(x)

Meaning: P holds for at least one object. FALSE if no object satisfies P.

Example: Same domain — at least one of the three has studied logic. One is enough.
A rumor that one warrior survived — just one confirmed survivor validates it entirely.

Unique Existential — ∃!x P(x)

Meaning: P holds for exactly one object. No more, no fewer.

Expansion: ∃!x P(x) ≡ ∃x [P(x) ∧ ∀y (P(y) → y = x)]
Example: ∃!x (x is the current Phoenix Network Director) — exactly one person holds that role.

Quantifier Negation Rules

OriginalNegationEnglish Translation
∀x P(x)≡ ¬∃x ¬P(x)"All" ↔ "There is none that isn't"
¬∀x P(x)≡ ∃x ¬P(x)"Not all" = "At least one isn't"
∃x P(x)≡ ¬∀x ¬P(x)"Some" ↔ "Not all fail"
¬∃x P(x)≡ ∀x ¬P(x)"None" = "All fail"
⚠ Critical trap: Negating "everyone" does NOT give you "no one." ¬∀x P(x) = "Not everyone" = "at least one person doesn't" — NOT "no one."

You step away from −∞ and land in the middle.

Power Set

If |A| = n, then |𝒫(A)| = 2ⁿ

A = {sword, shield} → |A| = 2 𝒫(A) = {∅, {sword}, {shield}, {sword, shield}} → |𝒫(A)| = 4 = 2²
Every subset is a possible loadout. Two weapons yield four loadouts. Every additional item doubles the possibilities.

Worked Examples

1. "Every student who passed the exam received a certificate."
   Let P(x) = "x passed",  C(x) = "x received a certificate"
   ∀x (P(x) → C(x))
   In sets: passers-set ⊆ certificate-holders-set
2. "Some Phoenix Network member knows both logic and rhetoric."
   Let L(x) = "x knows logic",  R(x) = "x knows rhetoric"
   ∃x (L(x) ∧ R(x))
   In sets: L ∩ R ≠ ∅

   ¬∃x (L(x) ∧ ¬D(x))  ≡  ∀x (L(x) → D(x))
   In sets: logic-knowers ⊆ domain-havers

Inference Rules

The 11 licensed moves of formal logic

What Are Inference Rules?

Inference rules are the licensed moves of formal logic. A proof is a sequence of steps where each line follows from previous lines via a named, validated rule. Each rule is shown as: Premise(s) / horizontal line / Conclusion.

Two categories:

  • Rules of Inference (Introduction/Elimination): Derive new statements from existing ones
  • Rules of Replacement (Equivalences): Swap a subformula for a logically equivalent one — can be applied to ANY subformula, not just whole lines

Rules of Inference

1

Modus Ponens (MP)

"The mode of putting — affirming the antecedent"

P → Q
P
───────
∴ Q

Reading: If P implies Q, and P is true, then Q must be true.

1. If the beacon is lit, the fleet will sail. (B → F) 2. The beacon is lit. (B) 3. ∴ The fleet will sail. (F) — MP on 1, 2
The prophecy fires. The condition was met; the consequence is now unavoidable.
2

Modus Tollens (MT)

"The mode of taking — denying the consequent"

P → Q
¬Q
───────
∴ ¬P

Reading: If P implies Q, and Q is false, then P must be false.

1. If the relic is intact, the seal holds. (R → S) 2. The seal does not hold. (¬S) 3. ∴ The relic is not intact. (¬R) — MT on 1, 2
The seal has broken. We work backwards from consequence to cause.
⚠ Warning: Affirming the consequent (Q, P→Q ∴ P) — INVALID. Denying the antecedent (¬P, P→Q ∴ ¬Q) — INVALID.
3

Hypothetical Syllogism (HS)

"Chaining conditionals"

P → Q
Q → R
───────
∴ P → R

Reading: Transitivity of implication — chain two conditionals into one.

1. If forge is hot, metal softens. (F → M) 2. If metal softens, it can be shaped. (M → S) 3. ∴ If forge is hot, metal can be shaped. (F → S) — HS on 1, 2
A chain of oaths — A swore to B, B swore to C. A is bound to C, even without ever meeting.
4

Disjunctive Syllogism (DS)

"Eliminating a disjunct"

P ∨ Q
¬P
───────
∴ Q

Reading: One of P or Q is true. P is false. Therefore Q must be true.

1. The spy entered by east gate or west gate. (E ∨ W) 2. Not east gate. (¬E) 3. ∴ West gate. (W) — DS on 1, 2
Two suspects. One is cleared. The other is convicted by elimination.
5

Constructive Dilemma (CD)

(P → Q) ∧ (R → S)
P ∨ R
───────
∴ Q ∨ S

Reading: Two paths (P or R), each leads somewhere (Q or S). Since one path must be taken, one destination must be reached.

1. If advance, gain ground; if retreat, regroup. (A → G) ∧ (R → E) 2. Will advance or retreat. (A ∨ R) 3. ∴ Will gain ground or regroup. (G ∨ E) — CD on 1, 2
Two roads, each with its own reward. You must walk one. Therefore you must earn one reward.
6

Destructive Dilemma (DD)

(P → Q) ∧ (R → S)
¬Q ∨ ¬S
───────
∴ ¬P ∨ ¬R

Reading: If neither outcome is acceptable, neither antecedent can be maintained.

Both roads are blocked. Therefore neither journey can be completed.
7

Simplification (Simp)

P ∧ Q
───────
∴ P       (also valid: ∴ Q)

Reading: If both P and Q are true together, P alone is certainly true.

8

Conjunction (Conj)

P
Q
───────
∴ P ∧ Q

Reading: If P is true on one line and Q on another, combine them.

9

Addition (Add)

P
───────
∴ P ∨ Q

Reading: If P is true, "P or Q" is automatically true — regardless of Q.

💡 Note: Addition feels counterintuitive but is a critical setup move — it manufactures a disjunction that a later Disjunctive Syllogism can consume.
10

Absorption (Abs)

P → Q
───────
∴ P → (P ∧ Q)

Reading: If P implies Q, then P implies (P and Q) — because asserting P guarantees Q anyway.

11

Resolution (Res)

"Primary tool in automated theorem proving"

P ∨ Q
¬P ∨ R
───────
∴ Q ∨ R

Reading: The shared variable P and ¬P cancel. Remaining disjuncts merge.

1. Scout reports or alarm sounds. (S ∨ A) 2. Scout doesn't report or gate closes. (¬S ∨ G) 3. ∴ Alarm sounds or gate closes. (A ∨ G) — Res on 1, 2

Rules of Replacement (Equivalences)

These can be applied to any subformula in any line — not just whole statements.

NameRule
Double Negation (DN)¬¬P ≡ P
De Morgan's (DeM)¬(P ∧ Q) ≡ ¬P ∨ ¬Q
¬(P ∨ Q) ≡ ¬P ∧ ¬Q
Implication (Impl)P → Q ≡ ¬P ∨ Q
Contraposition (Contra)P → Q ≡ ¬Q → ¬P
Exportation (Exp)(P ∧ Q) → R ≡ P → (Q → R)

Proof Templates

Four proof strategies with skeletons and worked examples

What Is a Proof?

A formal proof is a finite, ordered sequence of lines where every line is either a premise (given) or follows from earlier lines via a named inference rule. The final line is the conclusion to be established. A proof doesn't argue — it demonstrates.

Proof Anatomy

Line #StatementJustification
1.P → QPremise
2.PPremise
3.QModus Ponens (1, 2)

Premises first, labeled "Premise." Justification names the rule + line numbers. Goal is always the last line.

Direct

Template 1 — Direct Proof

When to use: The conclusion is a straightforward consequence of the premises.

Strategy: Apply inference rules step by step, moving forward from premises toward the conclusion.

Skeleton

Goal: Show [CONCLUSION]
1. [Premise 1]           Premise
2. [Premise 2]           Premise
n. [Intermediate]        [Rule] (refs)
z. [CONCLUSION]          [Rule] (refs)  ∎

Worked Example

Given: P → Q, Q → R, P  |  Prove: R

1. P → Q      Premise
2. Q → R      Premise
3. P          Premise
4. Q          Modus Ponens (1, 3)
5. R          Modus Ponens (2, 4)  ∎

Narrative: We're given P→Q and Q→R. Also given P. Applying MP twice chains us from P all the way to R.

Following a lit path through the dark — each torch lights the next; walk the chain to the end.
Contradiction

Template 2 — Proof by Contradiction

Reductio ad Absurdum

When to use: The conclusion is hard to reach directly, or is a negation. Assume the opposite — watch it collapse.

  1. Assume ¬C (negation of conclusion) as a temporary premise
  2. Derive a contradiction — X ∧ ¬X
  3. Since the assumption led to impossibility, it must be false
  4. Therefore C is true

Skeleton

Goal: Show [C]
1. [Premises]              Premise
k. ¬C                      Assumption for Contradiction
n. X                       [Rule] (refs)
n+1. ¬X                    [Rule] (refs)
n+2. X ∧ ¬X                Conjunction (n, n+1) ← Contradiction
n+3. C                     Reductio ad Absurdum (k–n+2)  ∎

Worked Example

Given: P ∨ Q, ¬Q  |  Prove: P

1. P ∨ Q      Premise
2. ¬Q         Premise
3. ¬P         Assumption for Contradiction
4. Q          Disjunctive Syllogism (1, 3)
5. Q ∧ ¬Q     Conjunction (4, 2)  ← Contradiction
6. P          Reductio ad Absurdum (3–5)  ∎
The locked-room argument. You assume the killer escaped through the window — but the window was sealed from the inside. The assumption destroys itself.
💡 Best for: Proving negative claims, or when every direct path is blocked.
Contrapositive

Template 3 — Proof by Contrapositive

When to use: Conclusion is P → Q and proving ¬Q → ¬P is easier. They are logically equivalent.

Equivalence: P → Q  ≡  ¬Q → ¬P   (Contraposition)

Skeleton

Goal: Show [P → Q]
Equivalent goal: Show [¬Q → ¬P]
1. [Premises]               Premise
k. ¬Q                       Assumption (conditional proof)
n. ¬P                       [Rule] (refs)
n+1. ¬Q → ¬P                Conditional Proof (k–n)
n+2. P → Q                  Contraposition (n+1)  ∎

Worked Example

Given: P → Q, P → ¬Q  |  Prove: ¬P

1. P → Q       Premise
2. P → ¬Q      Premise
3. ¬¬P         Assumption for Contradiction
4. P           Double Negation (3)
5. Q           Modus Ponens (1, 4)
6. ¬Q          Modus Ponens (2, 4)
7. Q ∧ ¬Q      Conjunction (5, 6)  ← Contradiction
8. ¬P          Reductio ad Absurdum (3–7)  ∎
Rather than proving the sword can cut the stone, you prove: if the stone were uncut, the sword could not exist as described. Since the sword exists, the stone was cut.
Cases

Template 4 — Proof by Cases (Exhaustion)

When to use: Premises contain a disjunction P ∨ Q. Prove the conclusion holds in every case.

  1. Identify disjunction P ∨ Q in the premises
  2. Case 1: Assume P — derive C
  3. Case 2: Assume Q — derive C
  4. Since all cases lead to C, and one must hold, C is established

Skeleton

Goal: Show [C]
1. P ∨ Q                       Premise
─── Case 1: Assume P ───────────────
k.   P                         Assumption (Case 1)
m.   C                         [Rules]
─── Case 2: Assume Q ───────────────
m+1. Q                         Assumption (Case 2)
n.   C                         [Rules]
─────────────────────────────────────
n+1. C                         Proof by Cases (1, k–m, m+1–n)  ∎

Worked Example

Given: P ∨ Q, P → R, Q → R  |  Prove: R

1. P ∨ Q      Premise

Fuzzy & Probabilistic Logic

Degrees of truth, linguistic hedges, and probabilistic reasoning

The Problem with Binary Logic

Classical (Boolean) logic is binary — every statement is TRUE (1) or FALSE (0). But natural language is not binary. "The water is hot." "She is tall." "It will probably rain." None of these are cleanly TRUE or FALSE — they live on a spectrum. Fuzzy logic and probabilistic logic are the formal tools built for this reality.

Two Distinct Systems

Core questionTo what degree is X true?How likely is X to be true?

Key distinction: Fuzzy logic says the statement itself has a partial truth value. Probabilistic logic says the statement is still fully TRUE or FALSE — we just don't know which, and express uncertainty as odds.

Fuzzy Operators

Let μ(P) denote the fuzzy truth value of P.

OperatorFormulaNotes
NOTμ(¬P) = 1 − μ(P)Mirrors across 0.5

Worked Example — The Base Rate Trap

A disease affects 1% of the population. A test is 95% accurate (true positive rate). You test positive. What is the real probability you have the disease? P(Disease) = 0.01 P(Positive | Disease) = 0.95 P(Positive | No Disease)= 0.05 P(Positive) = (0.95 × 0.01) + (0.05 × 0.99) = 0.059 P(Disease | Positive) = (0.95 × 0.01) / 0.059 ≈ 16.1% Despite a 95% accurate test, a positive result means only ~16% chance of actually being sick — because the disease is rare. The prior crushes the likelihood.

Why This Matters for Rhetoric and Argument

Example: "Most experts agree…"

This sentence simultaneously makes three claims:

  • Fuzzy: The degree of "expert agreement" is high (≈ 0.8)
  • Probabilistic: The probability that a randomly-selected expert agrees is high
  • Quantifier: "Most" ≈ Near +∞ on the spectrum — but NOT at +∞

Three patterns to watch for:

  • Vagueness exploitation — Using fuzzy terms to avoid commitment
  • Base rate neglect — Ignoring priors when presented with striking evidence
  • Quantifier slippage — Moving from "some" to "most" to "all" without justification

Summary — Three Layers of Truth

LayerSystemTruth ValuesQuestion Answered
BinaryClassical Logic{0, 1}Is this TRUE or FALSE?
GradedFuzzy Logic[0, 1]To what degree is this true?
UncertainProbabilistic Logic[0, 1]How likely is this to be true?

These are not rivals — they answer different questions. A sophisticated reasoner deploys all three: classical for valid inference chains, fuzzy for vague predicates and natural language, probabilistic for evidence, uncertainty, and belief updating.
